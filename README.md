# 🛒 Supermarket Sales Analysis

## 📌 Project Overview
This project analyzes supermarket sales data using Microsoft Excel.  
The goal is to clean and analyze the data, identify sales patterns, and create an interactive dashboard.

## 🛠 Tools & Skills
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Sales Analysis

## 📊 Dashboard
The interactive Excel dashboard includes:

- Total Sales: **$322,966.75**
- Total Orders: **1,000**
- Average Rating: **6.97**
- Sales by Product Line
- Sales by City
- Sales by Payment Method
- Interactive filters for City, Customer Type, and Gender

## 🔍 Key Insights
- **Naypyitaw** generated the highest total sales.
- **Food and Beverages** generated the highest sales among product lines.
- **Health and Beauty** had the lowest sales among product lines.
- **Cash** was the highest-selling payment method.
- The dashboard allows users to dynamically filter the analysis by city, customer type, and gender.

## 📁 Project File
`Supermarket_Sales_Analysis.xlsx`

The Excel workbook contains the cleaned data, Pivot Tables, Pivot Charts, and interactive dashboard.

## 🎯 Project Goal
This project was created to practice practical data analysis skills and demonstrate the ability to turn raw sales data into an interactive Excel dashboard.
